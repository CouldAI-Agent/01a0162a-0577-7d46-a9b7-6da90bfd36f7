# Nodavlat OTMdan Davlat OTMga Perevod Qoidalari

Bu ilova O'zbekiston Respublikasida xususiy (nodavlat) va xorijiy oliy ta'lim muassasalaridan davlat OTMlariga o'qishni ko'chirish (perevod) bo'yicha amaldagi shartlar va qoidalarni qulay tarzda ko'rsatib beruvchi ma'lumotnoma hisoblanadi.

## Xususiyatlari
- **Zamonaviy va qulay dizayn:** Ma'lumotlarni osongina o'qish imkoniyati.
- **Asosiy qoidalar bo'limi:** Arizalar vaqti, test sinovlari, o'tish ballari, yo'nalishlar mosligi va super-kontrakt shartlari.
- **Barcha qurilmalar uchun mos:** Mobil telefonlar, planshetlar va kompyuter ekranlarida chiroyli ko'rinadi.

## Texnologiyalar
- **Flutter** - UI yaratish uchun.
- **Dart** - Asosiy dasturlash tili.
- Material 3 dizayn tizimi.

## Ishga tushirish
Ilovani mahalliy kompyuteringizda ishga tushirish uchun quyidagi buyruqlardan foydalaning:
```bash
flutter pub get
flutter run
```
